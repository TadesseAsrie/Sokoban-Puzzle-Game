# Sokoban Puzzle Game

A modern Sokoban puzzle game built with HTML, CSS, and JavaScript.

## Features

- 10+ Challenging Levels
- Keyboard Controls
- Mobile Touch Controls
- Move Counter
- Timer
- Local Storage Save
- Dark/Light Theme
- Sound Effects
- Level Progression
- Win Detection
- Responsive Design

## Controls

### Keyboard
- Arrow Keys → Move Player
- W → Up
- A → Left
- S → Down
- D → Right

### Mobile
- On-screen directional buttons

## Objective

Push all boxes onto the target positions to complete the level.

## Game Rules

- Push one box at a time.
- Boxes cannot move through walls.
- Boxes cannot push other boxes.
- Complete all targets to win.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)


## Installation

1. Download project files.
2. Open index.html in a browser.
3. Start playing.
